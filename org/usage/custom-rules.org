#+title: Custom Rules
#+hugo_weight: 230

Power users can define default visual representations or styles for specific selections (e.g., chains, residues). Custom rules are applied automatically when opening a structure in the *Mol** viewer.

*How to Add a Custom Rule*:
1. Open the *Mol* Linker popup* by clicking the extension icon in your browser toolbar.
2. Navigate to the *Options* tab.
3. In the *Custom Rules* section, click *Add Rule*.
4. Fill in the fields using the [[https://molstar.org/viewer-docs/molviewspec][MolViewSpec expression language]]:
   - *Name*: A descriptive label (e.g., "Active Site").
   - *Selection*: A MolViewSpec selector (e.g., ={ "chain_id": "A", "residue_number": [100, 110] }=).
   - *Representation*: Choose a type (e.g., "highlight", "surface") and set properties like color or opacity.
5. Click *Save*. The rule will apply to all future structures.
