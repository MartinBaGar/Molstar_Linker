* About the extension

Researchers often encounter molecular structure files (.pdb, .cif, .gro, etc.) while browsing repositories, datasets, or institutional storage. Downloading these files manually just to visualize them in a separate tool disrupts workflows and slows discovery.

Mol* Linker eliminates this friction. It automatically detects structure files on supported sites and injects a one-click badge to open them directly in the *Mol** web viewer. No downloads, no context-switching. Just instant, interactive visualization.

* Install the extension

Install Mol* Linker in two simple steps. Choose your browser below:

*Chrome, Edge, or Brave*
1. Open the [[https://chromewebstore.google.com/detail/clemcfbjdnmakcllpobdkmhlbobfbomd?utm_source=item-share-cb][Chrome Web Store page for Mol* Linker]].
2. Click *Add to Chrome* (or *Add to Edge* / *Add to Brave*) and confirm the installation.

*Firefox*
1. Open the [[https://addons.mozilla.org/en-US/firefox/addon/mol-linker/][Firefox Add-ons page for Mol* Linker]].
2. Click *Add to Firefox* and confirm the installation.

The extension will activate automatically. No restart is required.

* Where the extension work by default
Mol* Linker works out-of-the-box on the following sites. The badge appears automatically next to supported file links.

| *Site*       | *Trigger Condition*                                                             | *Caveats/Notes*                                                                                        |
|------------+-------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------|
| GitHub     | File extensions: .pdb, .cif, .bcif, .mol, .sdf, .xyz, .ent, .ccp4, .mrc, .map | Badge appears next to file links in the file tree or raw file button.                                |
| GitLab     | File extensions: .pdb, .cif, .bcif, .mol, .sdf, .xyz, .ent, .ccp4, .mrc, .map | Badge appears next to file links in the file tree or download button.                                |
| Figshare   | File extensions: .pdb, .cif, .bcif, .mol, .sdf, .xyz, .ent, .ccp4, .mrc, .map | Badge appears next to download links. File extension detection may fall back to parent element text. |
| Zenodo     | File extensions: .pdb, .cif, .bcif, .mol, .sdf, .xyz, .ent, .ccp4, .mrc, .map | Badge appears next to file links in the file table.                                                  |
| Nextcloud  | File extensions: Detected from file list elements.                            | Badge appears next to file links. URLs are constructed using WebDAV paths.                           |
| FileSender | File extensions: Detected from download links or parent element text.         | Badge appears next to download links. Only single-file downloads are supported.                      |
