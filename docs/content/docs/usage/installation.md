## Install Mol\* Linker {#install-mol-linker}

Install Mol\* Linker in two simple steps. Choose your browser below:

**Chrome, Edge, or Brave**

1.  Open the [Chrome Web Store page for Mol\* Linker](https://chromewebstore.google.com/detail/clemcfbjdnmakcllpobdkmhlbobfbomd?utm_source=item-share-cb).
2.  Click **Add to Chrome** (or **Add to Edge** / **Add to Brave**) and confirm the installation.

**Firefox**

1.  Open the [Firefox Add-ons page for Mol\* Linker](https://addons.mozilla.org/en-US/firefox/addon/mol-linker/).
2.  Click **Add to Firefox** and confirm the installation.

The extension will activate automatically. No restart is required.
