Installation

Mol* Linker is available and fully compatible on Firefox and Chromium web browsers. It can also be used on mobile officially on Firefox and non-officially on Chromium solutions. Refer to the Installation section for more information.

How to use it

Having Mol* Linker enabled will automatically inject badges next to the structure files you want to see. Simply pay a visit to the supported websites and see what has changed ! You can also open your file from the browser context menu (right-click). Get more information on what it looks like and how to use it in the Usage section.

Where to use it

Mol* Linker works out-of-the-box on the following sites. The badge appears automatically next to supported file links.

  • Code/Version Control: GitHub, GitLab
  • Data/Research Repositories: Figshare, Zenodo
  • File Storage/Sharing: Nextcloud, FileSender

In addition to the default websites, Mol* Linker can also open structures hosted on private instances of your favorite hosts (i.e myunit.gitlab.com). It is convenient if you work with private data that you don't want to expose to the public. Refer to the Custom Domains section to know more !
